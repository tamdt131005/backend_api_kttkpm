# Diagram Data Pack

## Muc dich
Bo file nay chua du lieu san (nodes, edges, mapping) de ve 4 loai bieu do:
- Package diagram
- Component diagram
- Class diagram
- Deployment diagram

Tat ca du lieu duoc trich theo codebase hien tai cua du an backend_api_kttkpm.

## Danh sach file
- package-diagram-data.md
- component-diagram-data.md
- class-diagram-data.md
- deployment-diagram-data.md

## Cach su dung nhanh
1. Mo file du lieu tuong ung voi loai bieu do.
2. Lay bang Node List va Edge List de ve tren draw.io, Figma, Visio.
3. Neu dung Mermaid, copy khoi "Mermaid Seed" va dieu chinh.
4. Neu can thuyet minh trong bao cao, dung phan "Narrative Notes".

## Quy uoc chung
- Node ID: ma dinh danh ngan gon, de tham chieu.
- Type: actor, package, component, class, database, external, artifact.
- Edge Label: mo ta quan he/chuc nang ket noi.
- Direction: huong phu thuoc hoac huong giao tiep.

## Ghi chu
- Du lieu nay huong den muc tieu bao cao hoc phan, uu tien de hieu va de ve.
- Co the bo sung node moi neu codebase phat sinh module moi.
